# Bom-Estudante-
Bom Estudante é um simulador de preparação para concursos públicos em Angola. Disponibiliza milhares de questões sobre legislação, História, Geografia, Administração Pública, cultura geral, patriotismo, Português, Matemática e testes psicotécnicos, com cronómetro, correção, explicações e resultados para acompanhar o desempenho.
